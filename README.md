# My Portfolio

## 概要
本ポートフォリオは、私自身の人物像・スキル・制作物を一つの体験として伝えることを目的に制作したWebサイトです。  
自然をテーマにしたデザインとアニメーションを取り入れ、「閲覧する」のではなく、  
「体験する」サイトになるよう設計しました。  

メイン作品として音楽アプリ **Fika Beats** を掲載し、設計〜実装までの工程をまとめています。  

---

## コンセプト
- ユーザーに寄り添うフロントエンドエンジニア像の表現
- スクロールによってストーリーが進む構成
- PCとモバイルで体験が変わるインタラクション設計
- 視覚的に理解できるスキル表現

## 注意
PC版とMobile版でアニメーションを最適化しているため、  
DevToolsの画面サイズ切替のみでは挙動が一致しない場合があります。  
表示確認時はページのリロードを行ってください。

## セットアップ方法

### 1. リポジトリ取得
```bash
git clone https://github.com/himawari1013/portfolio.git
cd portfolio
```

### 2. 起動方法

#### 方法A：ブラウザで開く
　index.html をブラウザで直接開いてください。

#### 方法B：Live Server（推奨）
1. VSCodeでフォルダを開く
2. index.html を右クリック
3. Open with Live Server
